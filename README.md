 My First To-Do List Project

Description

My To-Do List is a simple web-based project used to add and manage daily tasks. Users can enter a task and add it to the task list. This project is created using HTML, CSS, and JavaScript.

Requirements

- HTML
- CSS
- JavaScript
- GitHub
- Web Browser

Features

- Add new tasks
- Display tasks in a list
- Simple and easy-to-use interface
- Clear task input after adding
- Works on a web browser
- Hosted using GitHub Pages

Technologies Used

- HTML – Creates the webpage structure
- CSS – Designs the webpage
- JavaScript – Adds functionality to the Add Task button
